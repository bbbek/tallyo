# Tallyo

Fast personal expense and income tracker. Works as a web app (PWA) and as a Telegram Mini App. All data stays on your device.

- Live: https://bbbek.github.io/tallyo/
- Quick add from iOS Shortcuts: `?amt=350&note=Globus&method=apple_pay`
- Telegram `startapp` parameter: `qr-350`, `tr-350`, `ti-350` (decimal point = `d`), or `b_<base64url query string>`

Plain HTML, CSS and JavaScript, no build step.
